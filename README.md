SOLMAR — an original top-down open-world crime game in the coastal city of Solmar. Drive, steal cars, outrun the police across five wanted levels, and run five story missions as Rico, a driver for the fixer Mara Voss. Traffic, pedestrians, combat, a HUD with minimap, and WebAudio sound — all in a single static page, no build step, no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
